Sobre o Meu Vade Mecum

Fontes: importamos o texto HTML disponibilizado pelo Planalto. Consulte sempre o link oficial para confirmar alterações, dispositivos revogados e casos de formatação complexa.

Atualizações: o aplicativo verifica as leis cuja última conferência tem mais de 24 horas ao ser aberto com internet. Você também pode tocar em “Verificar alterações”. A função não monitora mudanças quando o aplicativo está fechado.

Anotações: selecione um trecho do dispositivo para marcar ou use “Anotar”. Ao atualizar uma lei, as notas não são apagadas; trechos alterados são indicados para conferência.

Armazenamento: textos importados, anotações, imagens e áudios ficam neste dispositivo e neste navegador, usando IndexedDB. Excluir dados do navegador pode apagá-los. Faça backups regularmente.

Sincronização: esta versão não faz login nem sincroniza entre celulares e computadores. Essa funcionalidade precisará de uma base em nuvem e autenticação.
